WHAT THIS PACKAGE CONTAINS

  One native library, on every runtime identifier the package supports
  (win-x64, linux-x64, osx-arm64):

    SDL_image   3.4.4   SDL3_image.dll / libSDL3_image.so / libSDL3_image.dylib

  Five components maintained by third parties are compiled into that library and are
  governed by their own licenses, one section each below:

    stb_image   the general image decoding backend
    tiny_jpeg   JPEG encoding
    NanoSVG     the SVG loader
    QOI         the QOI loader
    XPaint      parts of the GIF decoder

  All five are present on every runtime identifier.

A NOTE ON SCOPE

  This package depends on RocketWerkz.Brutal.Sdl and links against SDL3 at runtime.
  SDL3 is not contained in this package and is covered by that package's own notices.

  SDL_image can optionally be built against libpng, libjpeg, libtiff, libwebp, libavif,
  dav1d, aom and libjxl. This build enables none of them, none is contained in the
  shipped library, and none is attributed here.
