WHAT THIS PACKAGE CONTAINS

  One native library, on every runtime identifier the package supports
  (win-x64, linux-x64, osx-arm64):

    SDL_ttf   3.2.2   SDL3_ttf.dll / libSDL3_ttf.so / libSDL3_ttf.dylib

  Six third-party components are statically linked into that library and are governed
  by their own licenses, one section each below:

    FreeType        2.13.2   font rasterisation
    BDF driver               FreeType's contributed BDF font driver, separately licensed
    PCF driver               FreeType's contributed PCF font driver, separately licensed
    zlib            1.3      bundled inside FreeType, used to decompress font tables
    HarfBuzz        8.5.0    Unicode text shaping
    stb_rect_pack            glyph atlas packing for the renderer and GPU text engines

  zlib arrives two levels down: FreeType bundles its own copy and compiles it in when
  no system zlib is linked, which is the case here. Nothing in this package's own
  configuration asks for it.

A NOTE ON SCOPE

  This package depends on RocketWerkz.Brutal.Sdl and links against SDL3 at runtime.
  SDL3 is not contained in this package and is covered by that package's own notices.

  SDL_ttf can optionally be built against PlutoSVG and PlutoVG for colour-emoji
  glyphs. This build enables neither, neither is contained in the shipped library,
  and neither is attributed here.

  blocks governing the code actually contained here are reproduced. Each such omission
