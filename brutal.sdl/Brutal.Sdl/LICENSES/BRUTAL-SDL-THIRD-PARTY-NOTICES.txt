WHAT THIS PACKAGE CONTAINS

  One native library, on every runtime identifier the package supports
  (win-x64, linux-x64, osx-arm64):

    SDL     3.4.12    SDL3.dll / libSDL3.so / libSDL3.dylib

  SDL is not a single work. Ten third-party components are compiled into that
  library and are governed by their own licenses, one section each below:

    HIDAPI              USB/Bluetooth HID access, behind SDL's SDL_hid_* API
    yuv2rgb             YUV to RGB colour conversion
    SDL_gfx             the surface rotation used by the software renderer
    stb_image           the PNG decoding behind SDL's SDL_LoadPNG
    SDL_qsort           the sort behind SDL's SDL_qsort and SDL_qsort_r
    X.Org keysym table  key symbol to Unicode mapping, for X11 and Wayland
    XSETTINGS client    desktop scaling and DPI settings, for X11
    EDID parser         display EDID decoding, for X11 monitor names
    xdg-user-dirs       user-directory lookup, for the Unix filesystem backend
    Wayland protocols   24 protocol descriptions, compiled to C by wayland-scanner

  HIDAPI, yuv2rgb, SDL_gfx, stb_image and SDL_qsort are present on every
  runtime identifier.

  The X.Org keysym table, the XSETTINGS client, the EDID parser, xdg-user-dirs
  and the Wayland protocol code are present in the linux-x64 library only. The
  keysym table, XSETTINGS client and EDID parser are built for the X11 and
  Wayland video drivers, the xdg-user-dirs lookup for the Unix filesystem
  backend, and the protocol descriptions for the Wayland driver -- none of
  which the win-x64 and osx-arm64 builds use.

A NOTE ON SCOPE

  Only components contained in the shipped libraries are listed. SDL also vendors the
  Khronos EGL, OpenGL and Vulkan headers, which this package compiles against but does
  not redistribute in any form.

  Two further third-party bodies of code are compiled in and have no section below, because
  neither states a holder to attribute. miniz, the deflate implementation built alongside
  stb_image, states an unlicense.org public-domain dedication and names no holder. SDL also
  carries its own copy of the Sun Microsystems libm; it is built as a separate static library
  so that unreferenced symbols do not reach the shared library, and every call into it sits
  behind a build guard that the system C library satisfies on all three runtime identifiers.

  Where an upstream license file covers more code than this package ships, only the
  blocks governing the code actually contained here are reproduced. Each such omission
  is named where it occurs, so that nothing below should be read as truncated.
