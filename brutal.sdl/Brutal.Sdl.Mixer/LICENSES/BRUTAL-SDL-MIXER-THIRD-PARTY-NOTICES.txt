WHAT THIS PACKAGE CONTAINS

  One native library, on every runtime identifier the package supports
  (win-x64, linux-x64, osx-arm64):

    SDL_mixer   3.2.4   SDL3_mixer.dll / libSDL3_mixer.so / libSDL3_mixer.dylib

  Three decoders maintained by third parties are compiled into that library and are
  governed by their own licenses, one section each below:

    stb_vorbis   Ogg Vorbis decoding
    dr_flac      FLAC decoding
    dr_mp3       MP3 decoding

A NOTE ON SCOPE

  This package depends on RocketWerkz.Brutal.Sdl and links against SDL3 at runtime.
  SDL3 is not contained in this package and is covered by that package's own notices.

  SDL_mixer can optionally be built against libmpg123, libFLAC, libvorbis, libopus,
  libxmp, libgme, WavPack and FluidSynth. This build enables none of them and
  substitutes the header-only decoders named above. None of those optional libraries
  is contained in the shipped library, and none is attributed here.
