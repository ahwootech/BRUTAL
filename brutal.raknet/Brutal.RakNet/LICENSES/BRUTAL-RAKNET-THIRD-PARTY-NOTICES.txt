WHAT THIS PACKAGE CONTAINS

  One native library, on every runtime identifier the package supports
  (win-x64, linux-x64, osx-arm64):

    RakNet   4.081   RakNetDLL.dll / libRakNetDLL.so / libRakNetDLL.dylib

  RakNet is a C++ UDP networking library. Three further components are compiled into
  that library and carry terms of their own. Each has its own section below:

    Mersenne Twister MT19937   the pseudo-random number generator
    DR_SHA1                    the SHA-1 implementation
    SLikeNet                   the split-packet reassembly buffer

  The managed assembly, Brutal.RakNet.dll, holds interop bindings written for this
  package and contains no third-party code.

A NOTE ON SCOPE

  RakNet's upstream source tree carries a DependentExtensions directory holding bzip2,
  jansson, miniupnpc, OpenSSL, PortAudio and Speex. None of them reaches this package.
  The build compiles the library from RakNet's Source directory alone, and the shipped
  binaries import nothing beyond the platform socket and C runtime libraries. They are
  therefore not attributed here.

  Nothing below should be read as truncated.
